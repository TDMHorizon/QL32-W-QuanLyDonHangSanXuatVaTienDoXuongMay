# Nguồn tham khảo & quy tắc trích dẫn

## Quy tắc bắt buộc (toàn dự án)

1. Mọi nội dung **tham khảo / lấy từ bên ngoài** (công thức, API, bài viết, docs sản phẩm, đề bài…) **phải ghi rõ link nguồn** ngay tại chỗ dùng hoặc trong mục “Nguồn” của file đó.
2. **Không** viết công thức, số liệu, quy trình “mồ côi” không có nguồn.
3. Nếu **tự suy ra / thích nghi** từ nguồn (vd. đổi tên chỉ số cho đúng xưởng may), vẫn phải:
   - ghi link nguồn gốc, và  
   - ghi chú phần nào là **áp dụng / bổ sung của nhóm**.
4. Link nội bộ repo dùng đường dẫn file; link ngoài dùng URL đầy đủ `https://...`.
5. Khi thêm nguồn mới → cập nhật bảng dưới đây.
